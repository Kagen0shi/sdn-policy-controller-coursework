# SDN Policy Controller - курсова робота Свістула Данило Олександрович

Практична реалізація до курсової роботи на тему:
**«Впровадження Software Defined Networking для гнучкого управління маршрутами і доступом абонентів»**.

## Що моделюється

Проєкт імітує роботу SDN-контролера в кампусній мережі. Контролер для кожного потоку:

1. визначає роль абонента;
2. перевіряє політику доступу до сервісу;
3. будує маршрут у графі мережі;
4. генерує OpenFlow-подібні правила;
5. за потреби перебудовує маршрут після відмови каналу.

## Алгоритми для порівняння

- `static_acl` - статичні ACL і фіксовані маршрути;
- `sdn_shortest_path` - SDN-маршрутизація без політик доступу;
- `sdn_policy` - SDN з рольовими політиками доступу;
- `sdn_resilient_policy` - SDN з політиками доступу та перебудовою маршрутів після відмов.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Після запуску результати зберігаються в папку `results/`.

## Основні результати

- `summary_results.csv` - зведена таблиця метрик;
- `flow_decisions.csv` - рішення контролера для кожного потоку;
- `sdn_topology.png` - логічна схема SDN-мережі;
- `policy_matrix.png` - матриця рольових політик доступу;
- `efficiency_index.png` - порівняння інтегрального індексу ефективності;
- `policy_violations_comparison.png` - порушення політик;
- `recovery_success_comparison.png` - відновлення після відмов;
- `flow_rules_count.png` - кількість згенерованих правил;
- `avg_path_length_comparison.png` - середня довжина маршруту.
